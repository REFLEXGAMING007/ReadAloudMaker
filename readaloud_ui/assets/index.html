How ReadAloudMaker works

One folder, one EPUB, one audio file per chapter. The engine finds where every sentence is spoken and writes EPUB 3 media overlays so your reader can highlight the text while it plays.

Qwen3 Forced Aligner recommended

Qwen3-ForcedAligner-0.6B predicts a timestamp for every word. The packager copies the original EPUB byte for byte and only adds the audio, SMIL overlays and manifest entries.

  • ~32–43 ms average alignment error (model card)
  • Needs Python 3.12 + PyTorch + requirements-qwen.txt
  • GPU strongly recommended; CPU works but is slow

Classic compatibility

The original aeneas + syncabook pipeline. It synthesizes each fragment with eSpeak NG and aligns the audio features, then lets syncabook rebuild the EPUB.

  • Needs Python 3.9, aeneas, syncabook, FFmpeg, eSpeak NG
  • Useful when the Qwen environment is not installed

If an engine says “setup needed”

Qwen3:
  py -3.12 -m venv .venv-qwen
  .venv-qwen\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu124
  .venv-qwen\Scripts\python.exe -m pip install -r requirements-qwen.txt

Classic:
  py -3.9 -m pip install -r requirements.txt
  install FFmpeg and eSpeak NG, then add both to PATH

Both engines write output/<title>_readaloud.epub. Open it in Thorium Reader to hear the narration with live highlighting.
